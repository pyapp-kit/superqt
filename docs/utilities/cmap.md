# Colormap utilities

The building blocks of the colormap widgets
([`QColormapComboBox`](../widgets/qcolormap.md),
[`CmapCatalogComboBox`](../widgets/colormap_catalog.md), and
[`QColormapLineEdit`](../widgets/qcolormaplineedit.md)), for drawing
[cmap](https://cmap-docs.readthedocs.io/) colormaps elsewhere. They need the
`cmap` extra (`pip install "superqt[cmap]"`).
