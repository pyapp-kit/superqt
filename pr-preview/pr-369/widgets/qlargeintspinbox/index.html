QLargeIntSpinBox¶

A spin box for integers of any size. QSpinBox stores its value in a 32-bit integer, so it can't go beyond ±2,147,483,647; QLargeIntSpinBox stores a Python int, and its default maximum is 2**64 - 1.

It doesn't support the prefix, suffix, or special value text of QSpinBox. Its valueChanged signal emits an object (a Python int), because a Qt int couldn't carry large values.

from qtpy.QtWidgets import QApplication

from superqt import QLargeIntSpinBox

app = QApplication([])

spin = QLargeIntSpinBox()
spin.setRange(0, 10**15)
spin.setValue(2**40)  # a QSpinBox can't go above 2**31 - 1
spin.show()

app.exec()

QLargeIntSpinBox ¶

QLargeIntSpinBox(parent=None)

An integer spinboxes backed by unbound python integer.

Qt's built-in QSpinBox is backed by a signed 32-bit integer. This could become limiting, particularly in large dense segmentations. This class behaves like a QSpinBox backed by an unbound python int.

Does not yet support "prefix", "suffix" or "specialValue" like QSpinBox.

Subclass of QAbstractSpinBox

QLargeIntSpinBox inherits all of QAbstractSpinBox's methods, signals, and properties. Only those that superqt adds or changes are listed here.
