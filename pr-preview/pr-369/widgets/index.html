Widgets¶

Most of these widgets subclass the Qt widget they're most similar to, and follow Qt's API conventions (camelCase names, value()/setValue() pairs, and signals named like valueChanged), so they can be used wherever that widget is. Each page lists the Qt class and what superqt adds to it.

Sliders¶

QRangeSliderA slider with two or more handles, to select a range. QDoubleSliderA slider for floats. QDoubleRangeSliderA range slider for floats. QLabeledSliderA slider with an editable label for its value. QLabeledDoubleSliderA slider for floats, with an editable label for its value. QLabeledRangeSliderA range slider with editable labels for its handles and range. QLabeledDoubleRangeSliderA range slider for floats, with editable labels.

Numeric inputs¶

QLargeIntSpinBoxA spin box for integers of any size. QQuantityA magnitude and a unit, backed by pint.

Combo boxes¶

QEnumComboBoxA combo box with the members of an Enum. QSearchableComboBoxA combo box that filters its items as you type. QColorComboBoxA combo box for choosing a color. QColormapComboBoxA combo box for choosing a colormap. CmapCatalogComboBoxA searchable combo box with every colormap in the cmap catalog.

Lists and trees¶

QSearchableListWidgetA list with a text field that filters its items. QSearchableTreeWidgetA tree view of a mapping, filtered by a regular expression.

Text and buttons¶

QElidingLabelA label that shortens its text with an ellipsis to fit. QElidingLineEditA line edit that shortens its text with an ellipsis while it isn't being edited. QColormapLineEditA line edit that shows the colormap that its text names. QToggleSwitchA checkable button drawn as a toggle switch.

Containers and layouts¶

QCollapsibleA frame that hides or shows its contents when its header is clicked. QFlowLayoutA layout that wraps its items onto new rows to fit the width.
